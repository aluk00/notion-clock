Technical Infrastructure

The system operates on a headless cloud-synchronisation model. This ensures zero-latency communication between independent Notion widgets.

  • Storage: Google Cloud Firebase (Firestore)
  • Data Path: Staff Portal writes to "rota_requests" and "staff_directory" collections.
  • Update Cycle: Live Listeners push changes to Manager Hub in 0.1 seconds.
  • Handover: Replace "firebaseConfig" in source code to migrate to DMG corporate account.
