Technical Architecture

The system operates on a headless cloud-synchronisation model. This ensures zero-latency communication between independent Notion widgets.

  • Infrastructure: Google Cloud Firebase (Firestore SDK v11.6.1)
  • Security: Encrypted TLS transit; AES-256 at-rest encryption.
  • Sync Mechanism: Live Snapshots (onSnapshot) push data in ~100ms.
  • Ownership: Handover requires replacing "firebaseConfig" in source.
