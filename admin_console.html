Cloud Management Protocol

The Master Sync Reset

What does this do?

This button performs a Hard Reset of your cloud database. It wipes every single record in the 'staff_directory' collection and re-uploads the canonical 32-member DMG hierarchy from scratch.

When should you use this?

  • If duplicates appear in the directory that cannot be deleted manually.
  • If the management hierarchy becomes corrupted or broken.
  • If you need to instantly return to the "verified" starting structure.

How often should it be used?

Rarely. This is a disaster recovery tool. For regular updates (new starters or leavers), please use the Personnel Intake tab or the Remove buttons in the directory.
